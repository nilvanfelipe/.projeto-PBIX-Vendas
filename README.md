## Projeto Power BI - Comercial Xperiun

Objetivo: Criar um relatório de vendas para a empresa Xperiun com o objetivo de analisar e visualizar os dados de vendas.

Contexto: Analisar a base de vendas e metas para gerar insights e ajudar na tomada de decisão. A empresa vende roupas no setor de varejo.  

1. Entender o negócio:
    * O que vende?
    * Para quem vende?

2. Analisar os dados:
    * Fonte 1 (Base de Dados): `Base de Dados.xlsx`
    * Fonte 2 (Base de Dados com Metas): `Base_de_Dados_com_Metas.xlsx`

3. Principais indicadores de vendas:
- Total de Receita vs Meta.
- Custo Total 
- Margem de Lucro
- Ticket Médio
- Número de Clientes
- % de Clientes Ativos

4. Criação dos relatórios:
    * Visão Geral de Vendas
    * Análise de Vendedores
    * Análise de Desempenho


5. Insights para o negócio:
    * Quais são os produtos mais vendidos?
    * Quais são os vendedores com melhor desempenho?
    * Quais são os clientes com maior potencial?
    * Quais são as tendências de vendas?
    * Onde estão as maiores oportunidades?

7. Publicação no Power BI Service:
    * No painel de relatórios, no menu superior direito, clique em Arquivo > Publicar > Power BI Service.


8. Configuração de agendamento de atualização:
    * Atualização a cada 15 dias.
    * Script em Python para atualizar os dados e gerar o relatório.
    * Enviar e-mail com relatório para o cliente.
